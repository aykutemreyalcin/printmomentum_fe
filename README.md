# PrintMomentum frontend

React SPA for **printmomentum.com** — printable Etsy t-shirts ranked by climb speed.

## Stack

- React 19
- Vite 8
- TypeScript
- Vitest

## Run

```bash
npm install
npm test
npm run dev
```

Dev server proxies `/api` to `http://localhost:8080`.
